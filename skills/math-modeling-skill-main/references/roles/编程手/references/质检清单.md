# 编程手质检清单

完成代码和图表后，逐项完成以下检查。

---

## A. 代码质量检查

- [ ] **代码可运行**：代码能够正确运行，无语法错误和运行时错误
- [ ] **结果合理**：输出结果符合题目要求和建模预期
- [ ] **结构清晰**：模块划分合理，有函数注释
- [ ] **导入齐全**：所有必要的库导入语句完整
- [ ] **结果输出完整**：.csv + .txt 或终端输出齐全

## B. 可视化检查

### B1. 三类图表完备性（每题）

- [ ] **① 原始数据可视化 ≥ 1 张**：数据分布、相关性或时序趋势图
- [ ] **② 中间产物可视化 ≥ 1 张**：收敛曲线、模型对比或误差分析图
- [ ] **③ 最终结果可视化 ≥ 2 张**：核心结论的对比/预测/综合评价图
- [ ] **总计 ≥ 3 张**：每道题至少 3 张不同类型的图表

### B2. 图表质量

- [ ] **核心结论明确**：每张图都有清晰的 one-sentence 结论
- [ ] **面板无冗余**：每个面板承载独特的证据
- [ ] **颜色语义一致**：同一方法家族在不同面板中保持同一色系
- [ ] **中文显示正常**：无方块或乱码
- [ ] **SVG 文本可编辑**：`svg.fonttype='none'` 已配置
- [ ] **PNG 分辨率达标**：dpi=300
- [ ] **坐标轴精简**：仅保留左+下 spines，右+上已关闭
- [ ] **无网格线**：无网格线干扰
- [ ] **面板标签正确**：小写粗体 `a, b, c`，transAxes 定位，字号 22
- [ ] **图例无边框**：`frameon=False`
- [ ] **统计量完整**：p值、n数、误差棒定义清晰标注
- [ ] **文字色深合理**：深色背景浅色文字，浅色背景深色文字
- [ ] **图幅尺寸合适**：根据图表类型选择推荐 figsize
- [ ] **图表已关闭**：每个 `save_figure()` 包含 `plt.close(fig)`
- [ ] **HTML 面板已生成**：`figures/图表面板.html` 可正常打开
- [ ] **输出格式完整**：每个图同时输出 SVG + PNG

## C. 文件结构检查

- [ ] `data/`、`results/`、`figures/` 三个目录已创建
- [ ] 代码文件命名为 `问题X_求解.py/.m` 格式
- [ ] `README.md` 项目说明文档已创建
- [ ] 建模手分析文档和术语表未修改

## D. 表格处理检查

- [ ] 输入表格只读不写
- [ ] 结果表格保持原有结构
- [ ] 不添加/删除列或修改列名
- [ ] 输出到新文件，不覆盖原输入文件
- [ ] 使用 Excel 公式而非硬编码值
