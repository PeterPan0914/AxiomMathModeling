# 学术写作进阶技巧

## 一、段落流检查：一段一消息

### 核心原则

每个自然段只传达一个核心消息。

### 段落检查三步法

```
1. 找主题句 → 用一句话概括本段在说什么
2. 验证一致性 → 段内所有句子是否都在支持这个主题？
3. 检查连接 → 句子之间是否有明确的逻辑关系？
```

### 常见段落问题

| 问题 | 表现 | 修正方法 |
|------|------|---------|
| **无主题句** | 读完后不知道这段话在说什么 | 每段第一句点明本段核心 |
| **多主题** | 一段里塞了2-3个不同的事情 | 拆成多个段落 |
| **跳跃** | 句子之间逻辑断档 | 补充过渡句 |
| **堆砌** | 数据罗列但没有观点 | 数据+解读一起写 |

### 示例

```
❌ 问题段落（多主题 + 无主题句）：
本文采用遗传算法求解。适应度函数为总配送距离的倒数。交叉概率设为0.8。
在50代后收敛。变异概率为0.1。交通数据来自实时路况API。

✅ 修正段落（一段一消息）：
本文采用遗传算法求解路径优化问题，关键参数为交叉概率0.8和变异概率0.1。
算法在50代内收敛（图2）。交通数据来自实时路况API，保证了优化结果的时效性。
```

## 二、动词校准（美赛专用）

**美赛论文使用英语撰写**，动词的选择直接影响论文的专业性和可信度。

### 动词强度谱系

```
强（有直接证据）     → show, demonstrate, establish, confirm
中（有间接证据）     → suggest, indicate, reveal
弱（基于推理）       → appear, seem, may, could, likely
```

| 动词 | 证据强度 | 使用场景 |
|------|---------|---------|
| **show** | 强 | 实验结果直接支持结论时 |
| **demonstrate** | 强 | 通过多角度证据证明时 |
| **establish** | 强 | 首次发现或建立新结论时 |
| **confirm** | 强 | 验证已有理论或假设时 |
| **suggest** | 中 | 结果表明某种趋势，但证据不充分 |
| **indicate** | 中 | 数据指向某个方向但存在不确定性 |
| **reveal** | 中 | 揭示了意料之外的模式 |
| **appear** | 弱 | 现象观察，但机制不明确 |
| **may / could** | 弱 | 推测性结论 |

### 示例

```
❌ 过强（证据不足）：Our results prove that the model is optimal.
✅ 适中的强证据：The proposed model demonstrates a 18.3% reduction in
   delivery distance compared to the baseline GA.
✅ 中等证据：The results suggest that incorporating real-time traffic data
   improves routing efficiency under high-density conditions.
✅ 弱证据：The model may generalize to other urban delivery scenarios,
   though further validation is needed.
```

> 数学建模论文中，尽量使用 show 和 demonstrate 级别（有数值结果支撑时），
> 避免 prove 这种绝对化表述。用具体数据支撑动词强度。
