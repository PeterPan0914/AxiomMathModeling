# 论文自审框架

基于 nature-writing 的 paper-review.md 思想，结合数学建模论文特点设计的系统性自审流程。
在提交论文前，按以下四个轮次逐轮检查。

---

## 第一轮：论证逻辑审查

### 1.1 核心论证链

逐条检查论文的核心主张是否都有证据支撑：

```markdown
| 论文的核心主张是什么？ | 支撑证据在哪里？ | 证据充分吗？ |
|----------------------|----------------|-------------|
| [本文的主要结论] | [图/表/公式编号] | ✅/⚠️/❌ |
| [模型的创新点] | [在哪论证的] | ✅/⚠️/❌ |
| [结果的有效性] | [在哪验证的] | ✅/⚠️/❌ |
```

### 1.2 常见论证漏洞

| 漏洞类型 | 表现 | 修正 |
|---------|------|------|
| **悬空主张** | 结论没有数据支撑 | 添加引用到对应图表 |
| **证据不足** | 一个图表支撑了过多结论 | 补充更多证据或减少主张 |
| **跳跃逻辑** | A→C 跳过了 B | 补充中间推理步骤 |
| **循环论证** | 用结论本身证明结论 | 重新组织论证路径 |
| **稻草人** | 对比的基线方法过弱 | 选择公认的基线方法 |

### 1.3 反方测试

站在评阅老师的角度，对每个结论问：

> "这个结论的反面是什么？我的论文中有证据能反驳它吗？"

如果对于某个结论的反方说法，论文中没有对应的反驳证据，则这个结论的论证是不完整的。

## 第二轮：章节结构审查

### 2.1 摘要完整性

- [ ] **context**: 第一句是否交代了研究背景？
- [ ] **gap**: 是否点出了现有方法的不足？
- [ ] **approach**: 本文做了什么？
- [ ] **result**: 是否有具体数值结果？
- [ ] **implication**: 结果意味着什么？
- [ ] **boundary**: 适用范围是否交代？

### 2.2 引言完整性

- [ ] **field scale**: 问题背景和规模是否清晰？
- [ ] **bottleneck**: 难点是否点明？
- [ ] **prior attempts**: 已有方法是否综述？
- [ ] **gap**: 已有方法的不足是否清楚？
- [ ] **present study**: 最后一段是否清晰说明本文做了什么？

### 2.3 结果部分完整性

- [ ] **evidence ladder**: 结果是否按 system→validation→main result→comparison→analysis 递进？
- [ ] **每图有分析**: 每张图片是否都有 ≥100 字的分析？
- [ ] **数据说话**: 结果描述是否有具体数值支撑？

### 2.4 讨论部分完整性

- [ ] **advance defined**: 核心创新是否总结？
- [ ] **evidence interpreted**: 结果的实际意义是否讨论？
- [ ] **limitations explicit**: 局限性是否具体（给出边界条件）？
- [ ] **future concrete**: 推广方向是否具体可行？

---

## 第三轮：表述质量审查

### 3.1 AI味检查

扫描以下 AI 写作痕迹：

| 模式 | 是否出现 | 位置 |
|------|---------|------|
| "此外"、"关键的"、"深入探讨" 等AI高频词 | ✅/❌ | — |
| "不仅...而且..." 否定平行结构 | ✅/❌ | — |
| 强行将内容分成三组 | ✅/❌ | — |
| 模糊归因（"专家认为"） | ✅/❌ | — |
| 公式化的"挑战与展望" | ✅/❌ | — |
| 破折号过度使用 | ✅/❌ | — |
| 同义词循环（模型/算法/方法/框架切换不停） | ✅/❌ | — |
| 通用的积极结论（"前景广阔"等） | ✅/❌ | — |

### 3.2 数据准确性

- [ ] 所有数值前后一致（摘要 vs 正文 vs 图表）
- [ ] 单位标注正确
- [ ] 公式编号和引用一致
- [ ] 图表编号和引用一致
- [ ] 参考文献编号和引用一致

### 3.3 美赛专门检查

- [ ] 动词强度匹配证据强度（show/demonstrate vs suggest/may）
- [ ] 摘要无关键字行
- [ ] 首行无缩进（英文段落顶格）
- [ ] 数字使用一致（≤10 用单词，>10 用数字等）
- [ ] 时态一致（摘要用现在时，方法用过去时）
- [ ] Related Work 按主题综合法而非逐篇罗列

---

## 第四轮：格式规范审查

### 4.1 通用格式

- [ ] 纸张大小：A4（国赛）或 US Letter（美赛）
- [ ] 页边距符合要求
- [ ] 字体统一（国赛：宋体+黑体标题；美赛：Times New Roman）
- [ ] 行距一致
- [ ] 页码连续
- [ ] 图表编号连续

### 4.2 图表格式

- [ ] 图有图号+图题（图下方）
- [ ] 表有表号+表题（表上方）
- [ ] 三线表格式正确
- [ ] 图表来自编程手生成的 `figures/` 目录
- [ ] 图片分辨率 ≥300dpi

### 4.3 参考文献格式

- [ ] 引用格式统一（APA 或其他指定格式）
- [ ] 引用编号按出现顺序
- [ ] 所有引用在文中有对应标注
- [ ] DOI 完整

---

## 自审结论

完成四轮审查后，给出结论：

| 结论 | 含义 | 行动 |
|------|------|------|
| ✅ 通过 | 所有检查项通过 | 可交付 |
| ⚠️ 有条件通过 | 非关键项未通过，但不影响核心论证 | 标记改进项后交付 |
| ❌ 不通过 | 存在论证漏洞或关键格式问题 | 修复后重新审查 |
