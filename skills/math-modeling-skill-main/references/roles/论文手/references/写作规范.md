# 论文写作规范

## 一、人称约束

**禁止使用第一人称表述**：

| 禁止使用 | 应使用 |
|---------|--------|
| 本研究 | 本文、该研究 |
| 本论文 | 本文 |
| 我们 | （省略主语） |
| 笔者 | 本文 |
| 我们的 | 该、本文提出的 |

**正确示例**：
```
✓ 本文建立了多目标优化模型，解决了资源配置问题。
✓ 该模型采用层次分析法确定权重。
✗ 本研究采用层次分析法确定权重。
```

## 二、叙述方式规范

**避免过度分点，多使用整段叙述**：

| 应避免 | 推荐做法 |
|--------|----------|
| 大量使用 1. 2. 3. 分点 | 使用整段连贯文字 |
| 每段只有一句话 | 每段3-5句完整表述 |

**分点的合理场景**：模型假设（5-8条）、符号说明（表格）、算法步骤（3-5步）、模型优缺点

**正确示例**：
```
✓ 正确：多使用整段叙述
针对该优化问题，本文建立了基于整数规划的资源分配模型。首先，根据题目约束条件
确定了决策变量和目标函数；其次，通过分析各因素之间的关联关系，构建了约束条件
矩阵；最后，采用分支定界法求解该模型。该模型的优势在于能够同时考虑多个约束
条件，并给出全局最优解。
```

## 三、去AI味写作指南

基于 Wikipedia 的 "Signs of AI writing" 整理。

### 核心原则

1. **识别AI模式** - 扫描下文列出的AI写作特征
2. **重写问题段落** - 用自然的表达替换AI痕迹
3. **保持原意** - 核心信息和数据不变
4. **注入个性** - 注入真实的分析思考

### 常见的AI写作模式

#### 1. 过度强调重要性
**警惕词汇**：标志着、是一个重要的、关键作用、突显了其重要性、为...做出贡献、奠定了坚实基础

```
❌ 该模型的建立标志着数学建模领域的一个重要里程碑...
✅ 该模型采用线性规划方法，求解得到最优配置方案，目标函数值为1256.3万元。
```

#### 2. 宣传性和广告式语言
**警惕词汇**：拥有、深刻的、突破性的、著名的、令人震撼的

```
❌ 本文提出了一种突破性的优化方法，充分展示了数学建模的魅力。
✅ 本文提出了一种基于改进遗传算法的优化方法，在测试数据集上取得了97.3%的准确率。
```

#### 3. 模糊归因
**警惕词汇**：专家认为、一些批评者认为、行业报告显示

```
❌ 专家认为，该模型具有广泛的应用前景。
✅ 根据Deb等人2002年的研究，NSGA-II算法在多目标优化问题中表现优异。
```

#### 4. 带有-ing结尾的肤浅分析
**警惕词汇**：突显了...、反映了...、展示了...

```
❌ 该算法收敛速度快，突显了其在处理大规模优化问题时的优势。
✅ 该算法在100次迭代内收敛，求解时间比传统方法缩短了40%。
```

#### 5. 公式化的"挑战与展望"
```
❌ 尽管该模型取得了较好的效果，但仍面临一些挑战。
✅ 当数据量超过10000条时，算法运行时间显著增加，需要进一步优化数据结构。
```

#### 6. 过度使用的AI词汇
**高频AI词汇**：此外、与...保持一致、关键的、深入探讨、持久的、增强、促进、获得、复杂的/复杂性

#### 7. "三法则"过度使用
```
❌ 该模型具有准确性高、效率快、稳定性强三个优点。
✅ 该模型在测试集上的准确率为95.6%，单次求解时间为0.3秒。
```

#### 8. 优雅变体（同义词循环）
```
❌ 该模型...该算法...该方法...本方案...这一框架...
✅ 该模型...该模型...该模型...（适当重复比强行换词更自然）
```

### 注入真实感

**不要只是报告事实——对它们做出反应。**
- "这个结果出乎意料"比中立地列出优缺点更有人情味
- "该方法效果很好，但计算时间较长"比"该方法效果很好"更真实
- 每句话都有具体数据或信息支撑

### 数学建模论文特有注意事项

| ❌ 禁止使用 | ✅ 替代方案 |
|------------|------------|
| 此外、另外 | 直接陈述，或用"同时" |
| 关键的、核心的 | 具体说明作用 |
| 深入探讨 | 分析、研究 |
| 具有重要意义 | 具体说明意义 |
| 体现了... | 直接说明特征 |

```
❌ 本文深入探讨了遗传算法在优化问题中的应用，充分展示了其在解决复杂问题时的强大能力。
✅ 本文采用遗传算法求解旅行商问题。在50个城市规模下，算法在100代内收敛，
   最优路径长度为1234.5公里，比最近邻算法缩短了15.3%。
```
